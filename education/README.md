# 📚 PredictMind Web — Learn It Like You're 10

This is the **website** (the part you see in a browser) for PredictMind. It's where
a person can pick a coin, choose a strategy, and test it — without writing any code.

These notes are your textbook for the web app. Read in order; each explains **what**
the code does, **how** it's written, **why** we did it this way, and what **other
options** existed.

> New to *server, API, component, state, props*? The short version:
> - **Component** = a reusable piece of screen (a button, a form, a chart).
> - **State** = things that can change while you use the page (what coin you picked).
> - **API call** = the website phoning a back-end service to fetch or send data.

## What the web app is built with

- **Next.js** (React) — the framework that turns our components into web pages.
- **TypeScript** — JavaScript with type-checking, so mistakes are caught early.
- **Tailwind CSS** — styling by adding small class names (like `text-white`).
